# SKUID 运营工具箱使用说明

适用版本：**1.1.11**

SKUID 运营工具箱是一个 Chrome 浏览器插件，支持通过浏览器右上角扩展图标或普通网页上的香蕉悬浮按钮，随时进行 SKUID 转换、拍二发三利润计算、SPU 信息匹配和好评率计算。

[下载插件 ZIP](https://github.com/chandlerler/gpt-tools/raw/refs/heads/main/dist/skuid-separator-extension-v1.1.11.zip) · [查看 GitHub 仓库](https://github.com/chandlerler/gpt-tools)

## 一、安装与打开

1. 下载插件 ZIP，解压到一个固定保存的文件夹。
2. 在 Chrome 地址栏输入 `chrome://extensions/` 并打开。
3. 开启右上角的“开发者模式”。
4. 点击“加载已解压的扩展程序”。
5. 选择解压后**包含 `manifest.json` 的 `skuid-separator-extension` 文件夹**，不要直接选择 ZIP。
6. 打开或刷新一个普通网页，点击页面上的香蕉悬浮按钮。
7. 在面板顶部切换工具。入口按两行两列排列：第一行“SKUID 转换 / SPU信息匹配”，第二行“拍二发三计算 / 好评率计算”。

插件运行无需安装 Node.js、npm 或其他开发工具。加载完成后，请保留插件文件夹；浏览器仍需要读取其中的文件。

黄色香蕉采用透明背景，不带签名。鼠标悬停在香蕉上时会连续旋转，移开后停止；拖动期间暂停旋转。若系统开启“减少动态效果”，则保持静止。

香蕉按钮可拖动至页面左侧或右侧，插件会记住位置。点击面板右上角的“×”可收起面板。

### 通过浏览器右上角使用

1. 点击 Chrome 右上角的“扩展程序”（拼图图标）。
2. 找到“SKUID 运营工具箱”，点击名称即可打开工具面板。
3. 点击旁边的图钉，可将插件固定到工具栏，以后直接点击图标打开。
4. 在弹出面板中切换四个工具，使用转换分组、利润计算、底表上传、SPU 查询和好评率计算等功能。

这个入口不依赖网页上的香蕉按钮；在无法显示悬浮按钮的浏览器内部页面，也可从工具栏打开插件。

### 关闭或恢复网页悬浮窗

工具栏弹出面板的**右上角**提供“显示悬浮窗”复选框：

- 默认勾选：普通网页显示香蕉按钮，可点击展开浮窗。
- 取消勾选：隐藏该浏览器中所有网页的香蕉按钮及已展开浮窗；工具栏面板继续可用。
- 重新勾选：恢复香蕉按钮，点击后再展开网页浮窗。
- 设置自动保存，对已打开的网页同步生效，新打开或刷新后的网页也使用该设置。

网页浮窗右上角的“×”仅收起当前面板，保留香蕉按钮；要隐藏香蕉按钮，请使用工具栏内的“显示悬浮窗”开关。

两个入口使用同一份已保存底表。在任一入口上传或删除底表后，另一入口会同步更新。分隔方式、分组设置和计算参数也使用同一份本地存储。

点击弹出面板以外的区域会按 Chrome 的默认行为关闭弹出面板。重新打开时会加载已保存的设置和底表，但临时输入的 SKUID、查询条件及结果不会保留。

## 二、SKUID 转换

适用于将混合分隔的 SKUID 整理成统一格式，或批量生成京东商品链接。

### 操作步骤

1. 将 SKUID 粘贴到输入框，或点击“读取剪贴板”。
2. 选择输出方式。
3. 点击“转换并复制”，结果会显示在下方并复制到剪贴板。
4. 需要再次复制时，点击“复制结果”。

输入支持空格、换行、英文逗号、中文逗号、英文分号、中文分号和顿号混合使用。插件会忽略空白项，保留输入顺序；**不会自动去除重复 SKUID**。

| 输出方式 | 结果 |
| --- | --- |
| 英文逗号 | 多个 SKUID 用 `,` 连接 |
| 空格 | 多个 SKUID 用空格连接 |
| 换行 | 每行一个 SKUID |
| 链接 | 每行一个 `https://item.jd.com/{SKUID}.html` |
| 自定义 | 使用填写的分隔符连接，例如竖线或分号 |

选择“自定义”后，需要填写分隔符，最多 20 个字符。插件会记住上次选择的输出方式和自定义分隔符。

### 按数量分组

“自定义分隔符”右侧提供可选的 **每 ___ 个分组**，适用于需要分批粘贴或提交 SKUID 的场景。分组适用于所有输出方式，无需先选择“自定义”。

1. 输入或粘贴 SKUID。
2. 勾选“每 ___ 个分组”，填写每组数量，例如 `50`（默认值）。
3. 选择英文逗号、空格、换行、链接或自定义分隔符。
4. 点击“转换并复制”，下方按组分列展示。
5. 点击某列右上角的复制图标，只复制该组；列较多时，拖动结果下方的横向滚动条查看后续列。

例如共有 123 个 SKUID，每 50 个分组后：

| 第一列 | 第二列 | 第三列 |
| --- | --- | --- |
| 第 1～50 个，共 50 个 | 第 51～100 个，共 50 个 | 第 101～123 个，共 23 个 |

- 每列内部仍使用所选分隔方式；选择“换行”时，每行一个 SKUID；选择“链接”时，每行一个商品链接。
- 分组保持输入顺序及重复项，最后一组不足指定数量时按实际数量展示，不补空项。
- “转换并复制”和结果标题右侧的“复制全部”复制完整结果，沿用所选分隔符；需要分批复制时使用各列的复制图标。
- 默认不启用分组；取消勾选后恢复单个结果框。
- 分组数量必须为大于 0 的整数；留空、0、负数或小数会提示错误，且不会执行转换复制。
- 插件会记住是否启用分组及每组数量。已有输入时，修改分组或分隔设置会更新结果，但不会自动写入剪贴板。

### 示例

输入：

```text
10031208685973 10031208358356；10033347973969
```

选择“英文逗号”：

```text
10031208685973,10031208358356,10033347973969
```

选择“链接”：

```text
https://item.jd.com/10031208685973.html
https://item.jd.com/10031208358356.html
https://item.jd.com/10033347973969.html
```

此功能直接按输入内容拼接商品链接，不会验证商品是否存在。读取剪贴板失败时，可直接手动粘贴。

## 三、拍二发三计算

填写成本、售价及比例参数，点击“计算单均利润”，即可查看“不合单单均利润（拍一单）”和“合单后预估单均利润”。

| 输入项 | 填写说明 |
| --- | --- |
| 采购价 | 单件采购成本，例如 `10` |
| 物流成本 | 每个包裹的物流成本，初始默认值为 `1.8` |
| CPS 佣金服务费 (%) | 输入百分数，例如 5% 填 `5` |
| 售价 | 用于计算的单件售价，例如 `20` |
| 预估合单率 (%) | 输入百分数，初始默认值为 `60` |

所有输入均须为有效非负数，两个百分比不能超过 `100`。插件会保存填写的参数，重新打开时恢复；修改参数后需再次点击计算按钮。

### 当前计算口径

以下公式使用 `C` 表示采购价、`L` 表示物流成本、`P` 表示售价；`c` 和 `r` 分别为佣金比例和合单比例，例如 5% 使用 `0.05`，60% 使用 `0.60`。

```text
不合单单均利润 = P × (1 − c) − L − C

合单后预估单均利润
  = P × (1 + r) × (1 − c)
    − L × (1 − r / 2)
    − C × (1 + r)
```

合单估算以 100 单为基准：合单率为 60% 时，按 160 件的收入及采购成本、70 个物流包裹计算，最后除以 100。当前公式没有单独的赠品成本输入项；如业务需要另计赠品、税费或其他费用，应在评估结果时另行核算。

例如采购价 `10`、物流成本 `1.8`、CPS `5`、售价 `20`、合单率 `60`，显示结果为：

- 不合单单均利润：`¥7.20`。
- 合单后预估单均利润：`¥13.14`。

## 四、SPU 信息匹配

此功能根据上传的商品底表查询。SPU 用于归集同一商品，SKU 对应具体规格；一个 SPU 可以包含多个 SKU。

### 1. 准备底表

使用 `.xlsx` 文件，建议把商品数据放在名为“数据”的工作表中，第一行写列名，每个 SKU 占一行。

| 建议列名 | 是否必需 | 用途 |
| --- | --- | --- |
| 商品SPU_ID | 必需 | 将多个 SKU 归到同一 SPU |
| 商品SKU_ID | 必需 | 查询 SKU、复制 ID 和生成商品链接 |
| 供应商名称 | 推荐 | 展示 SPU 的供应商 |
| 商品采购价 | 推荐 | 展示每个 SKU 的采购价 |
| 实际京配物流成本 | 推荐 | 展示每个 SKU 的物流成本 |
| 京喜商品真实好评率 | 推荐 | 展示每个 SKU 的真实好评率 |

示例数据（仅用于说明查询规则）：

| 商品SPU_ID | 商品SKU_ID | 供应商名称 | 商品采购价 | 实际京配物流成本 | 京喜商品真实好评率 |
| --- | --- | --- | --- | --- | --- |
| 900001 | 100001 | 示例供应商 | 10 | 1.8 | 98 |
| 900001 | 100002 | 示例供应商 | 12 | 1.8 | 97 |
| 900001 | 100003 | 示例供应商 | 15 | 2 | 99 |

整理底表时请注意：

- 将 SPU_ID 和 SKU_ID 列设置为文本，避免长数字被 Excel 改写或丢失精度。
- 好评率建议填写普通数值 `98` 或文本 `98%`。当前插件不会将 Excel 百分比单元格的底层数值 `0.98` 自动换算为 `98%`。
- 表头须位于工作表前 20 行内。插件会识别列名；使用上表列名更便于匹配。
- 多个工作表不会合并导入，插件会选择列名匹配程度较高的一张；同等匹配时，名为“数据”的工作表会获得优先权重。
- 缺少 SPU_ID 或 SKU_ID 的数据行会跳过；同一 SKU_ID 重复出现时只保留首次出现的记录。
- 缺少推荐列仍可查询，但相关内容可能显示 `--`，导入状态会提示缺少的字段。

### 2. 上传或更换底表

1. 切换到“SPU信息匹配”。
2. 在“上传商品底表（.xlsx）”处选择文件。
3. 等待显示“已保存”，并核对文件名、SKU 数量、SPU 数量和导入时间。
4. 上传成功后即可查询。

插件只保存最新的一份底表。新文件解析成功后，会替换之前保存的底表；更换底表后，查询使用新数据。点击上传区域旁的“删除”可清除已保存底表。

### 3. 输入 SKU_ID 查询

在“输入 SPU_ID / SKU_ID”框内填写**一个 SKU_ID**，点击“查询信息”或按 Enter。

查询结果展示该 SKU 所属 SPU 下的全部 SKU：

- 实际输入的 SKU 排在第一条。
- 第一条与其他 SKU 之间显示浅色分割线。
- 其他 SKU 保持底表中的原顺序。
- 该 SPU 只有一个 SKU 时，不显示分割线。

例如使用上方底表，输入 `100002` 后，顺序为：

```text
100002  ← 输入的 SKU
──────── 浅色分割线
100001
100003
```

### 4. 输入 SPU_ID 查询

在同一输入框内填写**一个 SPU_ID**，点击“查询信息”或按 Enter。

插件按底表顺序展示该 SPU 下的全部 SKU，**不显示分割线**。例如输入 `900001`，结果依次为 `100001`、`100002`、`100003`。

若同一个 ID 同时出现在 SKU_ID 和 SPU_ID 中，当前查询会优先按 SKU_ID 匹配。

### 5. 查看信息与复制 SKU

结果顶部展示 SPU_ID 和供应商，下面逐条展示 SKU_ID、采购价、物流成本及好评率。

- 点击顶部 SPU_ID 可打开商品页面，链接使用该 SPU 在底表中的第一个 SKU。
- 供应商显示该 SPU 下首次出现的非空供应商名称。
- 点击“一键复制所有SKUID”，按当前展示顺序复制，每行一个。
- SKU 查询中，复制结果也会将输入的 SKU 放在第一行。
- 信息较多时可在工具区域内滚动；每条 SKU 信息保持单行，并在空间不足时缩小字号。

### 6. 批量生成商品链接

1. 在“根据一系列 SPU_ID 获取 SKU 链接”框内输入多个 SPU_ID。
2. 使用空格、换行、英文或中文逗号、分号、顿号分隔。
3. 点击“生成 SKU 链接”。
4. 点击任一链接访问商品页，或点击“复制”复制全部已生成链接。

每个 SPU 只取底表中的第一个 SKU 生成链接。未匹配的 SPU_ID 会列在提示中，成功匹配的链接仍会展示。

单个 ID 的详细查询与批量链接查询共用展示区域：执行另一种查询时，上一种结果会收起。

## 五、好评率计算

用于反推：在原有评价不变、新增评价全部为好评的前提下，最少还需新增多少条好评，才能让实际好评率达到目标。

### 填写方式

| 输入项 | 说明 |
| --- | --- |
| 当前评价数 | 当前全部评价的数量，填写非负整数 |
| 好评数（可选） | 当前好评的准确数量，不得超过当前评价数 |
| 当前好评率 (%) | 没有准确好评数时可填写，例如 95% 填 `95` |
| 目标好评率 (%) | 希望达到的比例，例如 98% 填 `98` |

好评数和当前好评率至少填一项；同时填写时优先使用好评数，并显示实际采用的当前好评率。百分比支持 0～100、最多 6 位小数。当前没有评价时，评价数填 `0`，好评数及当前好评率留空或填 `0`。

点击“计算需要新增的好评数”，或在输入框中按 Enter，查看：

- 最少需要新增的好评数（向上取整）。
- 计算采用的当前好评率。
- 新增后的评价总数及好评率。

填写的参数会保存，下次打开时恢复。修改参数后旧结果会隐藏，需重新计算。

### 计算示例与公式

当前评价数为 `1000`、好评数为 `950`（95%），目标为 `98%`：最少需新增 **1500 个好评**。新增后共有 2500 条评价、2450 条好评，实际好评率为 98%。

设当前评价数为 `N`、好评数为 `P`、目标比例为 `T`（98% 写作 0.98），则：

```text
新增后的好评率 = (P + x) / (N + x)
当 0 ≤ T < 1 且 N > 0 时：
最少新增好评数 x = max(0, 向上取整((T × N − P) / (1 − T)))
```

新增好评同时增加分子与分母，因此不能只用“目标好评数减去当前好评数”计算。

### 特殊情况

- **已经达到目标**：显示无需新增，即 `0 个好评`。
- **目标为 100% 且已有非好评**：有限数量的新增好评无法达到严格的 100%，界面会明确提示；这与平台显示值四舍五入为 100% 不同。
- **当前没有评价**：目标大于 0% 时，新增 1 条好评即可达到 100%；目标为 0% 时无需新增。
- **只有当前好评率**：按输入比例估算，不擅自将反推的好评数取整。平台显示比例可能已经舍入，所以结果会标注“预计”；填写准确好评数可得到精确结果。
- 结果中的百分比最多展示 4 位小数，是否达标按未舍入的数值判断。

## 六、数据保存与更新插件

插件使用浏览器扩展的本地存储，保存分隔方式、计算器参数、悬浮球位置和最新商品底表。商品底表在本地解析，查询直接读取已保存的数据；点击商品链接时才会打开相应京东页面。这些数据不会自动同步到其他浏览器或设备。

更新步骤：

1. 下载新版 ZIP 并解压。
2. 将新版插件文件复制到原来加载的插件目录。
3. 打开 `chrome://extensions/`，找到插件并点击“重新加载”按钮。
4. 刷新正在使用的网页，使其加载新版界面。
5. 核对版本号和底表状态；如未显示已保存底表，重新上传 `.xlsx` 文件。

只更新文件并重新加载原扩展时，通常会保留本地数据。卸载扩展或清除扩展数据可能导致已保存内容丢失，因此请保留原始底表文件。

## 七、常见问题

| 问题 | 处理方法 |
| --- | --- |
| 安装时提示找不到清单文件 | 选择包含 `manifest.json` 的目录，不要选择 ZIP 或它的外层目录 |
| 页面没有香蕉悬浮按钮 | 先从右上角扩展图标打开插件，确认已勾选“显示悬浮窗”；再确认扩展已启用、允许访问当前网站，并刷新普通网页；`chrome://` 等内部页面请使用工具栏入口 |
| 无法读取剪贴板 | 直接手动粘贴内容；复制失败时可手动选中转换结果复制 |
| 提示请先上传底表 | 选择 `.xlsx` 文件，等待显示“已保存”后再查询 |
| 上传后提示找不到有效列名 | 检查是否包含商品SPU_ID、商品SKU_ID，且表头在前 20 行内 |
| 提示未解析到有效数据行 | 检查每行的 SPU_ID 和 SKU_ID 是否均有内容 |
| 输入 ID 后没有匹配结果 | 核对当前底表、完整 ID 和 Excel 数字精度；详细查询框每次只输入一个 ID |
| 好评率显示为 `0.98%` | 将底表好评率改为普通数值 `98` 或文本 `98%`，再重新上传 |
| 同一个 SKU 只显示一条记录 | 导入时相同 SKU_ID 只保留第一条，请在底表中整理重复数据 |
| 切换查询后之前的结果消失 | 详细查询与批量链接查询互斥显示，属于当前交互设计 |
| 提示浏览器不支持解压 XLSX | 更新 Chrome 后重试 |
| 修改底表后查询仍是旧数据 | Excel 文件变化不会自动同步，需要重新上传 |

## 八、版本更新

### 1.1.11

- 新增好评率计算，支持准确好评数或当前好评率估算，并显示最少新增数量和新增后比例。
- 处理已达标、无评价、目标 100% 和输入错误等情况，保存计算参数。
- 四个工具入口改为 2×2：第一行 SKUID 转换 / SPU信息匹配，第二行拍二发三计算 / 好评率计算。
- 网页悬浮面板与工具栏弹出面板均支持新功能。

### 1.1.10

- 浏览器工具栏、扩展列表和扩展管理页的图标统一更换为透明背景黄色香蕉。
- 更新后在扩展管理页点击“重新加载”，即可刷新工具栏图标。

### 1.1.9

- 新增浏览器右上角扩展图标入口，在弹出面板中使用全部三个工具。
- 在弹出面板右上角新增“显示悬浮窗”开关，设置自动保存并同步到各网页。
- 关闭悬浮窗后仍可通过工具栏使用插件，重新开启后恢复香蕉按钮。
- 两个入口同步更新上传或删除的商品底表。

### 1.1.8

- 在自定义分隔符右侧新增可选的“每 N 个分组”。
- 按指定数量横向分列展示，每列右上角提供独立复制图标。
- 列数较多时支持底部横向滚动，保留复制完整结果功能。
- 支持记忆分组设置和正整数校验。

### 1.1.7

- 悬浮按钮更换为黄色香蕉，透明背景，无签名。
- 鼠标悬停时旋转，移开或拖动时停止，并支持系统减少动态效果设置。
- 保留点击打开面板、拖动吸附和原有三个工具。

### 1.1.6

- SKU 查询将实际输入的 SKU 置顶。
- 用浅色分割线区分输入的 SKU 与其他 SKU。
- SPU 查询保留全部 SKU 的底表顺序，不显示分割线。
- 复制全部 SKUID 时与当前展示顺序一致。
