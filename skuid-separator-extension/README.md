# SKUID 运营工具箱 Chrome 插件

这是一个基于 Manifest V3 的 Chrome 扩展。加载后会在所有普通网页显示齿轮悬浮球，提供 SKUID 分隔转换、拍二发三利润计算和 SPU 信息匹配三类常用运营能力。

## 功能

- 支持读取剪贴板中的内容，也可手动粘贴或输入。
- 自动识别空格、换行、英文逗号、中文逗号、英文分号、中文分号和顿号混用的 SKUID。
- 支持英文逗号、空格、换行和自定义分隔符。
- 点击“转换并复制”后自动将结果写回剪贴板。
- 记住上次选择的分隔方式。
- 齿轮悬浮球可拖动至左侧或右侧，并记住纵向位置；位于页面上方时，面板自动向下展开。
- 在同一悬浮窗中切换“SKUID 转换”和“拍二发三计算”两个工具。
- 拍二发三计算器支持采购价、物流成本（默认 `1.8`）、CPS 佣金服务费百分比、售价和预估合单率（默认 `60`），并展示不合单单均利润和合单后预估单均利润。
- 新增第三个工具“SPU信息匹配”：上传 `.xlsx` 底表后，插件会始终只保存最新一份底表；重新上传会先删除旧底表再保存新底表。
- 支持按列名自动识别：商品SPU_ID、商品SKU_ID、供应商名称、商品采购价、实际京配物流成本、京喜商品真实好评率；常用数据建议放在名为“数据”的 Sheet 中。
- 输入 SPU_ID 或 SKU_ID 都可查询同一 SPU 下的所有 SKU、采购价、物流成本、真实好评率和供应商；SPU_ID 会基于同一 SPU 下第一个 SKU 转为 `https://item.jd.com/{SKUID}.html` 可点击链接。
- 输入 SKU_ID 时，该 SKU 默认置顶，并用浅色分割线与其余 SKU 隔开；其余 SKU 保持底表顺序。仅有一个 SKU 时不显示分割线。
- 输入 SPU_ID 时，仍按底表顺序展示全部 SKU，不显示分割线。
- 查询到 SPU 后，可点击“一键复制所有SKUID”，内容会按每个 SKU 一行复制。
- 复制所有 SKUID 时使用当前展示顺序，SKU 查询中输入的 SKU 也排在最前。
- 支持批量输入 SPU_ID，按每个 SPU 从底表提取第一个 SKU，生成可直接点击访问且可复制的商品链接。
- 两个查询入口的结果互斥展示；执行另一个查询时，上一个结果会自动折叠。
- SKU 详细信息固定一行展示；内容过长时自动缩小字号，保证完整显示。

例如输入：

```text
;10031208685973 10031208358356 10033347973969
```

选择“英文逗号”后输出：

```text
10031208685973,10031208358356,10033347973969
```

## 安装方式

1. 在 Chrome 地址栏打开 `chrome://extensions/`。
2. 打开右上角的“开发者模式”。
3. 点击“加载已解压的扩展程序”。
4. 选择本文件夹（包含 `manifest.json` 的文件夹）。
5. 打开任意网页，右下角即可看到悬浮球；拖动它即可吸附到页面左侧或右侧。

## 使用方式

1. 复制一批 SKUID。
2. 点击网页右下角的悬浮球，并在顶部选择所需工具。
3. 使用“SKUID 转换”时，点击“读取剪贴板”，或直接将内容粘贴到输入框。
4. 选择输出分隔符，然后点击“转换并复制”。
5. 使用“拍二发三计算”时，填写采购价、物流成本、CPS 佣金服务费、售价和预估合单率，点击“计算单均利润”。
6. 使用“SPU信息匹配”时，上传 `.xlsx` 底表；上传成功后可输入 SPU_ID 或 SKU_ID 查询。

Chrome 对剪贴板读取要求由用户操作触发，因此插件使用“读取剪贴板”按钮，而不会在后台持续监听剪贴板。
